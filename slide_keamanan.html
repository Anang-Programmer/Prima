Keamanan & Privasi Data PRIMA

Arsitektur Cloud Modern untuk Perlindungan Data Petambak

1. Row Level Security (RLS)

Supabase & PostgreSQL

  • Akses data dikunci di tingkat baris database.
  • Petambak hanya bisa melihat & mengubah data tambaknya sendiri.
  • Mencegah kebocoran data silang antar-pengguna secara absolut.

2. Server-Side API Security

Next.js & Vercel

  • Aplikasi (WebView) tidak berkomunikasi langsung dengan database/AI.
  • API Key rahasia (Groq, Lynx, Bynara) tersimpan aman di sisi server.
  • Tidak ada celah eksploitasi kunci API dari sisi *client* (HP).

3. Autentikasi Terpusat

Supabase Auth (JWT)

  • *Login* dan sesi pengguna divalidasi menggunakan token aman (JWT).
  • Manajemen sesi yang ketat untuk mencegah akses akun tidak sah.
  • (Catatan: Firebase digunakan khusus untuk Push Notification/FCM).

4. Enkripsi In-Transit (HTTPS)

SSL/TLS Standar Industri

  • Semua komunikasi antara Flutter WebView ↔ Next.js ↔ Supabase dienkripsi penuh.
  • Melindungi data krusial dari penyadapan saat ditransmisikan.
